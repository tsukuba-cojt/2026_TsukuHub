第1条（適用） 1. 本規約は、ユーザーと当運営との間における、本サービスの利用に関する一切の関係に適用されます。 2. 当運営が本サービス上で別途定めるガイドライン、ルール、注意事項その他の個別規定（以下「個別規定」といいます。）は、本規約の一部を構成するものとします。 3. 本規約と個別規定の内容が異なる場合には、個別規定において別段の定めがない限り、個別規定が優先して適用されます。 ## 第2条（本サービスについて） 1. 本サービスは、筑波大学生を主な対象として、大学生活に関する情報を提供するサービスです。 2. 本サービスでは、以下の情報または機能等を提供することがあります。 1. 授業・履修に関する情報 2. 時間割に関する情報 3. 授業レビュー・口コミに関する情報 4. 学群・学類等の卒業要件に関する情報 5. 就職活動・インターンシップ等に関する情報 6. 学生生活に関連する情報 7. ユーザーの登録情報や利用状況等に応じた検索、推薦その他の機能 8. その他当運営が提供する機能 3. 本サービスは、筑波大学が運営または提供する公式サービスではありません。 4. 履修、卒業要件、授業、履修申請、各種手続きその他大学に関する重要な事項については、必ず筑波大学が公表する最新の公式情報を確認してください。 ## 第3条（利用登録） 1. 本サービスの利用を希望する者（以下「利用希望者」といいます。）は、当運営が定める方法に従って利用登録を行うものとします。 2. 当運営は、利用希望者が以下のいずれかに該当すると判断した場合、利用登録を認めない、または登録後に利用を制限することがあります。 1. 登録内容に虚偽、誤記または重大な記入漏れがある場合 2. 他人になりすまして登録した場合 3. 過去に本規約への違反等を理由として利用停止または登録抹消を受けたことがある場合 4. 第14条に定める反社会的勢力に該当し、または関与していると合理的に認められる場合 5. その他、当運営が本サービスの適切な運営のため利用を適当でないと合理的に判断した場合 3. 登録情報に変更が生じた場合、ユーザーは必要に応じて登録情報を更新するものとします。 ## 第4条（アカウント管理） 1. ユーザーは、自己の責任において、本サービスに関するアカウント、メールアドレス、パスワードその他の認証情報を適切に管理するものとします。 2. ユーザーは、自らのアカウントを第三者に貸与、譲渡、売買、共有その他これらに類する行為をしてはなりません。 3. ユーザーのアカウントを利用して行われた行為については、当該アカウントを保有するユーザーによる行為として取り扱う場合があります。 4. アカウントの不正利用または第三者による利用が判明した場合、ユーザーは速やかに当運営へ連絡するものとします。 ## 第5条（ユーザー投稿） 1. ユーザーは、本サービス上で授業レビュー、コメントその他の情報（以下「投稿コンテンツ」といいます。）を投稿できる場合があります。 2. ユーザーは、自ら投稿する投稿コンテンツについて、適法に投稿する権利を有していること、および第三者の権利を侵害していないことを保証するものとします。 3. ユーザーは、以下に該当する投稿を行ってはなりません。 1. 虚偽または著しく事実と異なる情報 2. 特定の個人を誹謗中傷する内容 3. 教員、学生その他第三者のプライバシーを不当に侵害する情報 4. 氏名、電話番号、メールアドレス、住所その他第三者を特定できる個人情報を本人の許可なく掲載する行為 5. 差別的、脅迫的、暴力的または公序良俗に反する内容 6. 著作権、商標権その他第三者の知的財産権を侵害する内容 7. 営利目的の広告、宣伝、勧誘またはスパム行為 8. その他当運営が不適切と合理的に判断する内容 4. 当運営は、投稿コンテンツが本規約に違反すると合理的に判断した場合、ユーザーへの事前通知なく、当該投稿コンテンツの全部または一部を非公開または削除できるものとします。 5. ユーザーは、当運営に対し、本サービスの提供、運営、改善、宣伝、分析およびAI・機械学習モデルの開発・改善に必要な範囲で、投稿コンテンツを無償で利用する権利を許諾するものとします。ただし、当運営はプライバシーポリシーおよび関係法令に従って情報を取り扱います。 6. 投稿コンテンツに関する著作権その他の権利は、当運営に移転するものではなく、原則として投稿したユーザーまたは正当な権利者に留保されます。 ##
