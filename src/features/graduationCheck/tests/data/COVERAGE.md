# ダミーCSVのケース一覧

2026年10月23日時点の対応一覧（`data/supportedDepartments.ts`）と要件定義（`data/gradRequirementData.ts`）に照合し、25学類・専門学群、49専攻・課程、70種類の卒業要件IDを収録した。

「入学年度」は画面で選択する年度。「確定／見込み」は卒業要件に計上する単位数であり、CSVの単位数の単純合計とは異なる。各CSVと同じ名前の `.expected.json` に、分類先・GPA・不足単位などの期待値がある。[データの構成と注意点](README.md)を参照。
