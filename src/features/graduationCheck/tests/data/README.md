## 追加した67ケースの基本構成

各CSVに次の10科目を配置した。科目番号・氏名・単位数はテスト用の架空データであり、実在する学生の成績や実際の科目の単位数を表すものではない。科目番号で照合する選択科目は各学類のプレフィックスに合わせ、必修や科目名による照合では要件に定義された科目名を使用する。

| 科目 | 単位数 | 評価 | 確認すること |
| --- | ---: | --- | --- |
| 学類・専攻ごとの必修科目 | 3 | A+ | 科目名の完全一致で必修に分類する |
| 学類・専攻ごとの選択科目 | 2 | A | 科目番号で専門または専門基礎へ分類する |
| 同じ区分の履修中の科目 | 2 | 履修中 | 確定単位から除外し、区分の上限内で見込みに計上する |
| 同じ区分の不合格科目 | 2 | D | 分類は保持し、単位から除外する。GPAの分母には含める |
| 専門基礎等の選択科目 | 2 | B | 専門基礎や、重複する規則の優先順などを確認する |
| 学士基盤科目 | 1 | C | 共通科目へ分類する |
| 認定された関連科目 | 2 | 認 | 単位に含め、GPA・A率から除外する |
| P評価の関連科目 | 1 | P | 単位に含め、GPA・A率から除外する |
| 不合格の関連科目 | 2 | F | 単位・GPA・A率から除外する |
| 科目番号のない認定科目 | 2 | 認 | 関連科目へ推測配分せず、未分類として保持する |

追加ケースのGPAは `(3 × 4.3 + 2 × 4 + 2 × 3 + 1 × 2) / 10 = 2.89`、A率は `(3 + 2) / (3 + 2 + 2 + 1) × 100 = 62.5%`。期待値はこの単位構成と要件定義をもとに固定してあり、テストの実行時に判定結果から期待値を生成しない。

区分の最低単位と上限は学類ごとに異なるため、次の点を区別している。

- 医学類・看護学類は専門の選択科目がないため、A・D・履修中の選択科目を専門基礎へ配置する。医学類は専門基礎5単位、看護学類は1単位の上限を確認する。
- 生物学類・工学システム学類は専門基礎の選択区分がないため、B評価の科目を関連科目へ配置する。
- 生物資源科学主専攻の `EG02` は専門と専門基礎の両方の規則に該当する。現行の定義順により、先にある専門の `EG` 規則へ割り当てる挙動を期待する。
- 物理学類は関連科目の必須小区分に合わせ、Aで始まる科目番号の関連科目を配置する。
- 社会工学類は専門基礎の科目名による分類を確認する。
- 開講年度2023〜2026年は実際の静的カタログJSONで照合する。2021・2022年のケースは、カタログの未対応年度として報告し、CSV情報で判定する挙動を確認する。

既存の情報メディア創成学類・情報科学類・数学類の3ケースは、それぞれ元のデータと期待値を維持している。

## `mast-2023-mixed.csv`

アップロード画面で次の条件を選択して使用する。

- 学類: 情報メディア創成学類
- 専攻: 情報メディア創成主専攻
- 入学年度: 2023

主に次の経路を確認するためのデータである。

- 科目名完全一致による必修判定（卒業研究A）
- 代替科目群による必修判定（微積分1・微積分2 → 微分積分A）
- 科目番号タグによる必修判定（情報科目6単位を4単位で上限計上）
- 専門・専門基礎・共通・関連の各選択区分への分類
- `D`評価の単位除外
- `履修中`の確定単位からの除外と、見込み単位への計上
- GPAとA率の計算
