# 卒業要件チェッカー統合テスト用CSV

`script/test_graduation_check.py` が、このディレクトリにあるすべてのCSVを読み込み、本番のCSV解析・カタログ照合・卒業要件判定を実行する。各CSVと同名の `.expected.json` に学類・主専攻・入学年度と期待結果を記載する。[実行方法とケース追加方法](../script/README.md)を参照。

## 科目名・科目数

2026年10月28日に全70件のCSVを拡充した。各CSVに20科目を追加し、通常のケースは10科目から30科目へ、既存の3ケースはそれぞれ情報メディア創成33科目・情報科学31科目・数学29科目へ増やした。追加科目は計1,400科目分である。

- 専門分野の講義・演習・実験等を14科目、英語・初修外国語・情報の共通科目を6科目追加した。
- 「選択科目（ダミー）」「履修中の専門科目」などの汎用名を、分野に合わせた具体的な科目名に変更した。評価・履修状態は「総合評価」列で確認できる。
- 科目名と科目範囲は、**ファイル名が示す入学年度の筑波大学履修要覧**を基準に見直した。個別名がなく科目番号の範囲だけで指定された科目は、`public/data/courses/tsukuba-YYYY.json` の固定カタログで科目名を補完した。出典の章・PDFページ・参照方法は各CSVの備考と [COURSE_SOURCES.md](COURSE_SOURCES.md) に記載した。
- CSVの「開講年度」は入学年度とは別である。2021・2022年入学のケースの追加科目は、2023年度開講の科目として記録した。適用する履修要覧はそれぞれ2021・2022年度である。
- 元からある科目の番号・単位数・評価は分類の検証用に維持した。具体名に変更した科目も、実際の科目番号・単位数との対応を保証するものではない。CSVの備考列で追加科目と区別している。

氏名・学籍番号・成績はすべて架空であり、実在する学生の履修記録ではない。全CSVを通じた科目数は延べ件数で、異なるケースに共通の科目を含む。

## 検証する成績・分類

元の評価・履修状態の組合せを維持し、履修要覧で確認した科目名による分類・必修充足・単位集計を固定期待値で検証する。

| 評価・状態 | 確認すること |
| --- | --- |
| A+・A・B・C | 合格科目の単位集計、GPA・A率 |
| D | 分類先を保持し、取得単位から除外し、GPAの分母に含める |
| 履修中 | 確定単位から除外し、上限内で見込み単位に計上する |
| 認・P | 合格単位に含め、GPA・A率から除外する |
| F | 取得単位・GPA・A率から除外する |
| 科目番号なしの認定科目 | 関連科目へ推測配分せず、未分類として保持する |

学類・主専攻ごとの区分上限・科目群の条件を反映するため、取得単位はCSVの合格単位の単純合計とは異なる。各ケースの固定期待値は同名の `.expected.json`、集計単位の一覧は [COVERAGE.md](COVERAGE.md) を参照する。期待値はテスト実行時には生成しない。科目の見直しに合わせて分類・必修の充足結果・カタログ対応年度・集計値を更新し、GPA・A率はCSVから別途計算して確認した。

開講年度2023〜2026年は静的カタログJSONで照合する。2021・2022年開講の科目は、カタログの未対応年度として報告し、CSV情報で判定する挙動を確認する。2021・2022年入学のケースでは、未対応の開講年度と対応済みの2023年度が混在する。

## `mast-2023-mixed.csv`

アップロード画面では、情報メディア創成学類・情報メディア創成主専攻・入学年度2023年を選択する。

必修の科目名完全一致（卒業研究A）、代替科目群（微積分1・微積分2 → 微分積分A）、科目番号タグ（情報科目の上限計上）、各選択区分、D評価、履修中、GPA・A率を確認するケースである。追加科目を含む最新の数値は同名の `.expected.json` を参照する。
