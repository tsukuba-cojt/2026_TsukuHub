# 卒業要件チェッカー統合テスト用CSV

`script/test_graduation_check.py` が、このディレクトリにあるすべてのCSVを読み込み、本番のCSV解析・カタログ照合・卒業要件判定を実行する。各CSVと同名の `.expected.json` に学類・主専攻・入学年度と期待結果を記載する。[実行方法とケース追加方法](../script/README.md)を参照。

| CSV | 学類・主専攻 | 確定／見込み | 主な確認内容 |
| --- | --- | --- | --- |
| `mast-2023-mixed.csv` | 情報メディア創成学類 | 18／20単位 | 必修の完全一致・代替科目群・情報科目の上限、5区分への分類 |
| `coins-ss-2023-mixed.csv` | 情報科学類・ソフトウェアサイエンス | 15／17単位 | 主専攻・専門基礎・関連の分類、小区分の最低単位を考慮した進捗 |
| `math-2023-mixed.csv` | 数学類 | 11／13単位 | 微積分・線形代数の科目群、5区分への分類 |

いずれも2023年度入学のケースで、D評価の単位除外、履修中の見込み単位への計上、GPA・A率も検証する。すべて架空データであり、実在する学生の成績ではない。

## `mast-2023-mixed.csv`

アップロード画面で次の条件を選択して使用する。

- 学類: 情報メディア創成学類
- 専攻: 情報メディア創成主専攻
- 入学年度: 2023

主に次の経路を確認するためのデータである。

- 科目名完全一致による必修判定（卒業研究A）
- 代替科目群による必修判定（微積分1・微積分2 → 微分積分A）
- 科目番号タグによる必修判定（情報科目6単位を4単位で上限計上）
- 専門・専門基礎・共通・関連の各選択区分への分類
- `D`評価の単位除外
- `履修中`の確定単位からの除外と、見込み単位への計上
- GPAとA率の計算
