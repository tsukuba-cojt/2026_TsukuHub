# 正規化卒業要件の配置規則

人が編集・監査する `NormalizedCurriculum` は、次の順序で配置する。

```text
requirements/
  <入学年度>/
    <学類キー>/
      <主専攻キー>.ts
```

例: `requirements/2026/coins/coins-ss.ts`

- 最上位は入学年度、次に学類、最後に主専攻とする。
- 年度をまたぐ暗黙の差分継承は行わず、各ファイルだけでその年度の完全な要件を読めるようにする。
- 同じルールを複数年度で共有する場合も、出典と適用年度を各年度ファイルで明示する。
- 生成済みの実行候補データも `compiled/<入学年度>/<学類>/<主専攻>.json` に同じ階層で出力する。
- `compiled/` は生成物なので手編集しない。

既存の `curriculum/pilots/` は形式検証用の移行前データである。内容を再監査した学類からこの
階層へ移し、`NormalizedCurriculum` から実行形式へのコンパイラ完成後に `pilots/` を廃止する。
