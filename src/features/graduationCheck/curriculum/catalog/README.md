# 年度別科目カタログ

卒業要件PDFだけでは判定できない同一授業・二重開設情報を、年度付きの固定授業JSONから
科目番号へ解決するための補助データである。卒業要件の根拠は公式PDFのままとし、カタログは
`MatcherResolution` の解決にだけ使用する。

対応範囲は2023〜2026年度入学であり、標準修業年限を超える在籍を前提にした年度は扱わない。
各年度の選定基準は、終了年度では次年度データへの切替直前の最終版、2026年度では実装日の
最新固定版である。

| 対象年度 | 元ファイル | スナップショット日 | 科目数 | 同一授業リンク | SHA-256 |
| ---: | --- | --- | ---: | ---: | --- |
| 2023 | `kdb-20240331.csv` | 2024-03-31 | 15,943 | 2,774 | `8aca44f7c164d35bbb4449a5198610260c96713a759de0d1f295d36127cbbeff` |
| 2024 | `kdb-20250331.csv` | 2025-03-31 | 14,822 | 2,201 | `3a74de3ea118a85c420cf67728a42f7155c834f6afff8682b8d15142139fbe15` |
| 2025 | `kdb-20251031.csv` | 2025-10-31 | 13,888 | 1,500 | `ed59d7f92b9faf6e60d9adbb7d50747027e4cdc9469b3a3e6154254205fdf13b` |
| 2026 | `kdb-20261016.csv` | 2026-10-16 | 13,496 | 1,470 | `b46050ba62c0ffa989402ef688321144118ea461262a68534b529f8c04988ca5` |

基礎となる全授業JSONを上流コミット
`b3d77356c21bad19dd3578f316b9fcec7f7f47a7`へ固定している。派生成果物には授業全体を複製せず、
備考欄の「科目番号と同一」から抽出した同一授業リンクと出典情報だけを保持する。

CSV形式の差異、解析警告、空行の除外は年度別授業JSONの生成段階で解決する。カリキュラム用
スナップショットはCSVを再取得せず、`public/data/courses/tsukuba-{年度}.json`だけを基礎にする。

```sh
npm run sync:curriculum-catalog
```

授業JSONを含む全成果物を再生成する場合は `npm run sync:catalog-assets` を使用する。

上流リポジトリはMPL-2.0を掲示している。大学由来の科目データ自体の利用条件は別途確認し、
出典・固定URL・ハッシュを成果物から削除しない。

## ブラウザ実行用の静的JSON

本番の卒業要件チェックでは、このTypeScriptスナップショットを直接バンドルしない。
`public/data/courses/tsukuba-{年度}.json`から次のコマンドで軽量な同一授業グループだけを生成し、
成績CSVに含まれる開講年度のファイルをブラウザ内で取得する。

```sh
npm run sync:graduation-catalog
```

出力先は `public/data/graduation/tsukuba-{年度}-cross-listings.json`。成績データや科目番号を
サーバーへ問い合わせるAPIは使用しない。
