# 運用対象外の比較資料

2026-10-28の対象範囲整理により、4年制課程の2021・2022年度入学分を現行の生成データから移した。
`compiled/` には2021年度4件・2022年度46件、計50件の完全スナップショットと年度別索引を保存する。
各科目要件JSONは移動前のSHA-256と一致することを検証し、内容を変更していない。
`rule-reviews-out-of-scope.json` は対象外年度の過去レビュー記録である。

このディレクトリを画面選択肢、現行の公開可否・監査未完了件数、スナップショット生成の入力に使わない。
現行の生成物は兄弟の `../compiled/` とその `manifest.json`、対応入学年度は
`../../data/supportedDepartments.ts` を正とする。

2021・2022年度PDFは出典として元の場所に保持し、`../audits/` にある過去の調査結果も保存する。
`data/requirements/` 内の過去ルール版とその動作テストは比較・履歴参照のために残す。
`*-22` というルール版IDだけで対象外とは判断しない。2023年度以降から共用される版もある。

医学類（6年制）の2022年度は現行の対応を維持し、ここへ移していない。
看護学類・医療科学類は4年制として2023年度以降を対象とする。
