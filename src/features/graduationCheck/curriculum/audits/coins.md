## 1. 範囲と出典

通常の4年制課程を対象とする。2022年度以前は運用・必須監査へ戻さず、旧22版・過去スナップショットを比較履歴として保持する。
編転入、早期卒業、移行者の属性別の履修許可は自動確定の対象外。
配置済み公式PDFのSHA-256と総ページ数を `officialSources.ts` と照合した。文書IDは
`tsukuba-graduation-requirements-<年度>`、表は別表第1（第3条関係）（情報科学類）。

| 2023 | 83 / 242 | 84 / 243 | 85 / 244 | 120 |
| 2024 | 84 / 247 | 85 / 248 | 86 / 249 | 121 |

全12表の列境界、必修・選択、結合セル、注記を画像で比較した。2023は回転して確認、2025は文字抽出が崩れるため画像を根拠とした。
科目番号・実名称・単位は `public/data/courses/tsukuba-2023.json`〜`2026.json` と照合し、卒業条件の根拠とは区別する。

## 4. 科目DBとの照合と必修の混入防止

全4年度で次の番号・名称・単位を照合した。

| 対象 | 確認した番号 | 扱い |
| --- | --- | --- |
| 必修実験 | GB26403/26503（SS）、GB36403/36503（IS）、GB46403/46503（IM）、各3 | 主専攻ごとの実験名で照合 |
| 卒業研究A/B | GB19948/19988、GB19958/19998、各3 | 専用タグでA/Bを各3に限定。他学類の同名卒研を拾わない |
| 専門語学A/B | GB19091/19111、GB19101/19121、各2 | 専用タグでA/B各2。旧1.5単位版・特別専門語学を自動で読み替えない |
| 指定基礎 | GB11601/11621、GB12301、GB12601、GB12801/12812 | 指定名称を確認 |
| 基礎英語 | GB13614/13624、各2 | A/Bの名称を確認 |
| 基礎のGA | GA152系・GA153系、GA182系・GA183系 | 数学・プログラミングの同名複数開設を確認 |

GB19041/19051/19071/19081の旧1.5単位版が2023〜2025固定DBに残るが、開講年度と入学年度を混同して現行2単位へ換算しない。
他学類の同名卒業研究A/Bを必修へ算入していた不具合と、同名複数開設による必修単位の過大加算を修正した。
数学・プログラミング等の同名必修は引き続き名称照合を含み、開設組織や移行者属性をすべて確定できるわけではない。

2023の正規化パイロットが注15を「プログラミング入門I/II→A/B」としていたが、画像・抽出文とも同名A/Bである。
根拠のないI/IIの代替定義を削除し、注15を未解決へ戻した。数学の代替も学生属性なしに承認できる状態ではない。
2024〜2026を含む正規化パイロットの全条件と実行時結果の突き合わせはHR-019で継続する。
各パイロットの一部 `approved` フィールドをもって年度全体や実行形式の承認済みとはしない。

教職タグの9/99境界と表にいう「教職に関する科目」の対象一覧、英語31H/J/K/Lタグの完全性、
新旧科目・外国語特例、必修超過の振替は独立確認を要する。個別認定を科目名の印象から推測しない。
GBとの二重開設が分かる追加枠の科目は現行では関連から除き、自動で別番号の専門へ振り替える処理は行わない。
補集合が固定カタログの他の除外番号との同一授業も除く点は、個別認定の完全な代替ではない。

人による完了条件:

1. 学類長の重複認定一覧・単位互換・外国語／教職の対象範囲を確認する。
2. 新旧必修番号・移行者読み替え・同名開設・必修超過配分を確認する。
3. 履修前提を卒業時の合計と分離して、必要な履修履歴・学生属性を定義する。
4. HR-019で代表履修例と正規化パイロットの全条件・年度差を比較する。
5. 別の確認者が12表・注記・実装・境界テストを独立承認する。

HR-018は確認中、全12年度別スナップショットの詳細承認状態は `unsupported`、人の確認者名・確認日は未記入。
HR-019も共有部分の画像確認・修正には着手したが、上記比較は未完了。画面・手動入力は5分類のままとし、
詳細の内数不足・確認不能を粗い進捗へ混ぜない。
