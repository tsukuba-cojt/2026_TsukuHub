## 4. 必修名・固定カタログとの照合

公式表の専門必修は「卒業論文（○○）」「○○研究-a」「○○研究-b」の合計10単位で、○○は学類長の指定。
従来の「卒業論文（哲学）」「哲学研究-a」等の主専攻名の機械的挿入では実科目を照合できなかった。
2023〜2026年度の固定 `public/data/courses/tsukuba-<年度>.json` から番号・名称・単位を確認し、
確認できた名称の候補を6・2・2単位群として登録した。カタログは名称確認にだけ使用し、指定資格の根拠としない。

| 主専攻 | 固定カタログで確認した領域名 | 代表番号 |
| --- | --- | --- |
| 哲学 | 哲学・倫理学、宗教学 | AB62K38 / K12 / K22 |
| 史学 | 日本史、ユーラシア史、歴史地理学（論文名は日本史学・ユーラシア史学） | AB71K38 / K12 / K22 |
| 考古学・民俗学 | 先史学・考古学、民俗学・文化人類学 | AB83K38 / K12 / K22 |
| 言語学 | 一般言語学、応用言語学、日本語学、英語学 | AB91K38 / K12 / K22 |

半角・全角括弧の両方を候補へ含めた。2022の固定科目カタログはなく、全領域・旧CSV表記の網羅性は未確認。
異なる領域の論文・研究a/bを混ぜても許可されるかは判定できない。名前が一致することだけで正式指定や
同一領域での組合せまで確認できたとはしない。

共通必修18単位は総合2・体育2・第一外国語4・第二外国語4・情報4・国語2。
総合はファーストイヤー／フレッシュマンセミナーと学問への誘いを候補化した。
第一・第二外国語の別々の4単位は従来の外国語合計8単位で代用しており、詳細条件としては未対応である。

## 5. 修正・検証と未解決事項

修正前の5失敗を確認後、年度ルーティング・主専攻別上限、主専攻内数、年度境界の番号範囲、
必修の実名称による消し込み、関連3小区分の個別上限を修正した。テストは5件にまとめ、
4主専攻・5年度、下限と1単位不足、78単位上限、11単位枠、重複・余剰配分、5分類方式を検証する。

未解決事項と人による完了条件:

1. 年度・主専攻別の学類長指定一覧を学校へ確認し、番号帯内の採用・除外と必修の同一領域組合せを確定する。
2. 専門基礎の指定11単位と追加枠の配分、専門・関連への余剰振替、未履修の指定科目の除外を独立確認する。
3. 第一・第二外国語、留学生・母語別の特例、2022カタログ・旧CSV名称を確認する。
4. 自動監査者と別の確認者が画像の列、年度差、実装、境界テストを承認する。

これらのため全20年度別ルールを `unsupported` とする。詳細判定の承認状態であり、5分類の
プロトタイプ運用を止める意味ではない。人の確認者・確認日は未記入で、`approved` にはしない。
