### 番号との対応・修正した誤判定

従来は「熱力学」「線形代数A」「卒業研究A」等を名前だけで必修へ入れていた。
必修に専用タグと単位上限を設け、同名他学類科目と並行クラスによる過大加算を防いだ。

| 対応 | 照合した番号 |
| --- | --- |
| 基礎実験学 | FF19401 |
| 主専攻番号d（物理2／電子3／物性4／分子5）の実験A/B | AはFFd0113/0123、BはFFd0133/0143。各族2まで |
| 同じdの卒研A/B | AはFFd9928/9938、BはFFd9948/9958。各族4まで |
| 基礎必修 | FF17011概論、FF18804/814熱力学、FF18664/674/684/694/FF18704/714解析学、FF18724/734/744/754線形、FF18784/794力学、FF18604/614/624/634/644/654電磁気、FF18761/771化学、FF19303/313物理実験、FF19203/213化学実験 |
| 専門英語1/2/3 | 各dのFFd0051/0061/0071。表にない全学共通の同名科目は含めない |
| 共通数学 | 数学リテラシーはFA011/012、微積分FA013/014/015、線形FA016/017/018 |
| 共通力学・電磁気 | 力学1はFCB1201/1211/1221/1231、2は1241/1251/1261、3は1271/1281/1291。電磁気1は1301/1311/1321/1331、2は1341/1351/1361、3は1371/1381/1391 |
| 共通化学 | 化学1はFE11171/11271、2は11181/11281、3は11191/11291 |
| 明記の実習 | FF13103/13203インターンシップ、FF14003/14103特別実習 |

2023固定DBのFF18764は「微積分1」1単位のため2023専用タグへ含めた。2024以降へ無条件には追加しない。
共通基礎の各科目は2023では各1まで、2024以降では公式指定群の選択15〜17へ分類する。
2024以降に同内容の複数クラスを取得した場合の詳細な同一授業認定・振替は別途確認が必要。

実習等の旧matcherはFF全体を許し、FF18の未確認基礎や自専攻未指定専門も0〜4へ入れていた。
明記された4実習・FA00・当該輪講名・他3主専攻の明確な選択群FFx5/FFx6だけに絞った。
「他主専攻が開設する専門」の全件一覧をこのprefixだけで確定したとは扱わず、対象を確認できないFFは未分類に残す。
当該輪講は名称を維持するが、固定DBだけでは現行の番号対応を確定できていない。
利用者が確認できた未分類は既存5分類で手動入力できる。

関連主枠ではFF、FA00、共通基礎指定、共通科目、資格等8/9を除外し、資格等を別枠へ入れる。
特設タグ固有の例外8049911等を関連主枠へ漏らさず、公式表の8/9の枠で扱う。
FA45124・FA45224は固定DB備考で応用理工学類の卒業単位に算入しないとされるためFA45も除外する。
これはPDFに直接書かれた番号としての引用ではなく、固定DBの注意書きによる限定である。
正式な学類長除外指定一覧は未取得で、現在の補集合だけで全件適否を確定できない。

## 5. 未解決事項・独立レビューの完了条件

正式な開設区分・学類長除外指定一覧、輪講番号、旧番号と同一授業の認定、言語・単位互換・早期卒業、
移行前取得の読替、必修超過の振替、実験・卒研開始時点の確認が必要。
各小区分に一度消費した科目を別欄へ再利用しないが、科目を分割しない厳密な欄間最適配分は保証しない。
表・年度差・番号対応・境界テストを別の確認者が承認するまでは詳細全16件 `unsupported`、HR-027は確認中。
画面と利用者の分類は5種類を維持し、小区分・時点・属性の不足を粗い進捗から減算しない。
