## 1. 範囲と資料

通常の4年制課程を対象とする。利用者の明示依頼により、従来未対応だった2026年度を監査・運用対象へ追加した。
2022年度以前は運用へ戻さず、旧21/22版・過去スナップショットは比較履歴として保持する。
編転入、早期卒業、移行者や留学生の個別許可の自動確定は対象外。

配置済みPDFのSHA-256と総ページ数を `officialSources.ts` と照合した。文書IDは
`tsukuba-graduation-requirements-<年度>`。全4年度の表・列境界・注1〜10をページ画像で確認した。

## 4. 科目DBとの対応と必修の混入防止

| 専門英語A | GC42102・GC42302、各1 | 専用タグで合計1を上限とする |

| データ工学概論 | GC13201、2 | 公式名称を確認 |
| コンピュータリテラシー | 2025・2026のGC12104、1 | 2025入学以降の必修へ追加 |
| プログラミング | 2023〜2025はGC12701、2026はGC12791、各2 | 名称で同じ必修へ照合 |

卒研と専門英語は全4開講年度のDBで確認した。以前は他学類の同名卒研や複数開設の専門英語をまとめて必修へ加算していた。
専用タグへ変更し、卒研A/B各3、専門英語A/B各1で制限する。
その他の数学・プログラミング等の名称照合には同名開設や条件付き代替の問題が残る。
複数開設を同時に履修した場合の超過分の振替は自動確定しない。
