# Q05・Q06 公開資料の調査結果

調査日: 2026-10-28。利用者の明示的な依頼に基づき大学公式サイトを検索した。
Q05は芸術の必修名・日本芸術の指定、Q06は他学類の指定・除外・番号対応を指す。
資料を見つけたこと、適用年度を確定したこと、実装・独立承認が済んだことは区別する。
画面・手動分類は従来の5種類を維持する。

## 1. Q05: 調査で解消・訂正した点

### 芸術学の必修は「英語基礎演習」

以前の監査の「芸術基礎演習A/B/C」は読み取り誤りだった。
手元の卒業細則を画像で再確認すると、全4年度とも「英語基礎演習A,B,C」、合計1単位である。

| 入学年度 | 元PDFのページ（PDF先頭を1とする） | 紙面ページ |
| --- | ---: | ---: |
| 2023 | 113 | 272 |
| 2024 | 114 | 277 |
| 2025 | 116 | 282 |
| 2026 | 116 | 284 |

[大学の2026開設授業科目表](https://www.tsukuba.ac.jp/education/ug-courses-openclass/2026/pdf/art-design.pdf)のPDF3頁は、
YAX3132〜YAX3182を「英語基礎演習（芸術）A-1/A-2/B-1/B-2/C-1/C-2」、各1単位とする。
2025公式科目表のPDF3頁、固定カタログ2023〜2026でも同じ6番号を確認した。
実装を番号タグへ訂正した。他学類の同名英語科目を名前だけで必修へ入れない。
詳細では6番号の合計から必要1単位を判定し、5分類では従来どおり小区分上限による減算をしない。

[公式の旧新読み替え表](https://www.geijutsu.tsukuba.ac.jp/school/curriculum/method/replacement/)も発見したが、
2018年度以前入学者用である。2023〜2026の読み替え根拠として流用しない。
今回の修正は架空の「芸術基礎演習」を英語へ読み替える処理ではなく、元の表の読み取り訂正である。

### 日本芸術のインターンシップ

2026公式科目表PDF34頁は、YBW2933「インターンシップ（日本芸術）」1単位を掲載し、
備考でJapan-Expert学生に限るとしている。2025公式科目表PDF28頁にも掲載され、
固定カタログの2023〜2026すべてに同番号・1単位がある。
従前の「2025以降のカタログ欠落」という監査記録は誤りで、ここで訂正する。
日本芸術必修の単独名称一致をYBW2933の番号指定へ修正した。
他領域や他学類のインターンシップを日本芸術必修へ一括追加しない。

## 2. Q05: 資料は見つかったが年度確定が残る点

[Japan-Expert公式カリキュラム](https://jp-ex.tsukuba.ac.jp/curriculum/)に
[共通科目表](https://jp-ex.tsukuba.ac.jp/jp/wp-content/uploads/2025/05/8c8616d34792571af67a0dd107015d9d.pdf)がある。
日本芸術に関係する「芸術以外」は、日本語・日本文化5科目、生物資源4科目、看護1科目の10名称で、
全名称を固定2023〜2026カタログで実番号へ照合できた。
番号候補は `q05-q06-web-evidence.json` に保存した。

PDFには適用入学年度・改訂日・科目番号が明記されていない。
URLの2025/05を適用年度とみなしたり、後年の表を過去の全入学年度へ一括適用したりしない。
指定一覧を一切入手できていなかった状態からは進んだが、年度別の適用履歴確認は残す。
実行定義の空matcherは今回は維持する。粗い5分類の関連進捗を、指定1単位の未確定によって減らさない。

[日本芸術カリキュラムモデル](https://jp-ex.tsukuba.ac.jp/jp/wp-content/uploads/2025/04/e3362df8f8abe3b2f638f84f44f98bac.pdf)も保存した。
これはビジュアルデザイン領域の履修例であり、共通科目例の名称も新しい共通科目表と異なる。
年度別の指定一覧の代わりには使わない。

[芸術の2026新入生ガイダンス](https://www.geijutsu.tsukuba.ac.jp/school/curriculum/y_cg_freshman/)では、
領域研究と領域特別演習は同一領域でなくてもよいが、特別演習I〜IIIは同一領域である必要がある。
卒業研究は同じ領域の特別演習Iの履修と未修得30単位以下を前提とする。
これで2026向けの組合せ・開始時点の説明は得られた。過年度への適用確認と詳細実装は残し、
フロントへ所属領域の必須入力を増やさない。

## 4. 保存・実装・次の作業

取得PDF11冊は卒業要件と同じ `curriculum/` に置いた。
URL・取得日・SHA-256・ページ数・年度の注意点は `officialSupplementarySources` と
`q05-q06-web-evidence.json` に保存した。本文を取得できなかった2024芸術科目表は保存済み資料に数えない。
年度別卒業細則の選択用 `officialCurriculumSources` へ補足資料を混ぜていない。

今回の実行定義変更は、Q05で元資料と実番号を確認できた英語基礎演習・日本芸術インターンシップの2点。
Q06は資料の発見・保存と残件の具体化までで、番号を推測して自動算入範囲を広げていない。
次は人文の4冊のコース別表を固定カタログへ照合する作業を手元で進められる。
学校へ尋ねるなら、JE共通科目表の年度別適用履歴、社会経済のBC/FH指定掲示、CE短期留学生の年度別除外一覧を優先する。
学校への連絡は行っていない。詳細のunsupported・独立承認待ちは維持する。
