## 3. 固定科目DBとの照合方法・結果

`public/data/courses/tsukuba-2023.json`〜`2026.json` の番号・科目名・単位を照合した。
本文の「工学システム学類開設」「社会工学類開設」「芸術専門学群開設」で番号の母集合をFG／FH／YA・YBに限定した。
開設元の注記がない行は、都市計画の資料でFH、芸術の資料でYA・YBとして照合する。
全半角・空白・ローマ数字の字体差を正規化して完全一致を調べ、似た名称への推測対応はしない。

JSONの `catalogYears` は**その開講年度の固定DBに存在した**ことを示す。
同じ科目が2024〜2026にもあることは、その年度入学者にも資格表が適用できる根拠にはならない。
`mappingState: candidate` は番号照合候補であり、学校による正式な全件対応承認ではない。

照合で残った注意点:

- 両資料の「社会のなかの建築デザイン」は、全4年度の指定開設元に完全一致候補を確認できなかった。別名へ読み替えない。
- 都市計画の歴史はFH45211・FH63081、都市計画原論はFH45201・FH63071と複数番号がある。
- 2023の地盤工学は表1単位に対してFG45771が2、FG45831が1。防災工学も表2に対しFG45821は1、FG45751は2。
- 芸術表の設計計画論は表1に対し2023のFG43821が2、FG43811が1。
- `creditsMatch: false` の候補を表と同じものと確定せず、別の単位一致番号があることも含めて保持した。
- その他の並行クラス・旧番号も候補として残し、同名だから全て重複取得できるとは扱わない。

## 4. 卒業要件との対応・今回の反映範囲

### 芸術専門学群

卒業細則の専門選択に明示された次の4科目は、今回の芸術資格表にも記載されている。

| 番号 | 固定DBの名称 | 表の単位 | 資格表の箇所 |
| --- | --- | ---: | --- |
| FG45901 | 建築設備 | 2 | PDF1ページ、④ |
| FH45051 | 建築関連法規 | 1 | PDF2ページ、⑨ |
| FH45061 | 建築経済 | 1 | PDF2ページ、⑧ |
| FH45071 | 建築生産 | 1 | PDF2ページ、⑧ |

この4科目計5単位は、実行時 `data/requirements/humanHealthArts.ts` の
`artSpecifiedSpecializedCodes` と専門0〜5の既存処理に一致する。
したがって、資料受領を理由に芸術の専門枠を新しく広げる必要はない。
例えば建築環境工学FG45911/FG55911、設計計画論FG43811も資格表には載るが、
卒業細則の上記4番号の専門枠へは追加せず、既存の他の科目欄に従って扱う。
芸術基礎演習A/B/C、Japan-Expert指定科目、日本芸術インターンシップの不明点も、この資格表では解消しない。

## 5. 残件と検証

出典URL・取得日2026-10-28・ハッシュは `officialArchitectCourseSources` に保存した。
ユーザー配置の都市計画・芸術資料は原本を保持し、別課程の資料を正しい工シス資料と偽って置き換えていない。
建築士資格の指定科目対応だけを卒業細則の該当欄へ用い、受験資格・実務経験条件の判定機能は追加しない。
学校への問い合わせや外部への連絡も行っていない。

境界テストは2件に集約した。全4年度のエネメカでFH/YA/YBの確認済み科目を専門へ数えること、
他課程だけの指定科目を混入させないこと、知的・機能には追加しないこと、芸術の指定4科目を勝手に広げないことを確認する。
機械可読の出典を対応する年度へ追加し、詳細の承認状態はunsupportedを維持した。
最終検証結果は `DEVELOPMENT_HANDOFF.md` に記録する。
