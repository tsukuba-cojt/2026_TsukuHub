Replitへの指示文

あなたは優秀なWebアプリ開発者です。
以下の要求仕様に基づいて、筑波大学生向け情報集約プラットフォーム 「TsukuHub」 のWebアプリMVPを作成してください。

1. 作りたいもの

筑波大学生が、授業・履修、サークル、就活・インターン、学食・生活情報、イベント情報などを一元的に探せるWebアプリを作成してください。

サービス名は TsukuHub です。

コンセプトは以下です。

筑波大学生の「知りたい」が、ここに全部ある。

初期版では、スマートフォンとPCの両方で見やすいレスポンシブWebサイトとして作成してください。

2. 技術スタック

以下の構成で作成してください。

フロントエンド：React
言語：TypeScript
スタイリング：Tailwind CSS
ルーティング：React Router
データ：まずはモックデータで実装
後からFirebase / Supabaseに移行しやすい構造にしてください

最初はログインやDB接続は本格実装せず、画面と基本機能が動くMVPを優先してください。

11. 追加で意識してほしいこと

このサービスは、就活特化サイトではなく、筑波大学生向けの総合情報ポータルです。

ただし、就活・長期インターンは重要カテゴリとして扱ってください。

情報カテゴリの優先度は以下です。

授業・履修
就活・キャリア
サークル・課外活動
生活・便利情報
イベント・お知らせ
留学・国際交流

TOP画面では、ユーザーが「何を探せばよいか分からない」状態でも情報にたどり着けるように、注目キーワード・カテゴリカード・新着情報を分かりやすく配置してください。
