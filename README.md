# TsukuHub

## 1. プロダクト名

TsukuHub

---

## 2. 概要

TsukuHubは、筑波大学生が大学生活に必要な情報を一か所で探せる情報プラットフォームです。

サークル、授業、過去問、住居、飲食店、アルバイト、遊び、留学、就活・インターンなどの情報を整理し、学生が迷ったときにすぐ確認できる状態を目指します。

また、学年や目的に応じて必要な情報を探せるようにし、学生が「今、自分に必要な情報は何か」を分かりやすくすることを目指します。

---

## 3. 背景・目的

筑波大学生に必要な情報は、SNS、LINE、大学公式サイト、先輩の口コミなど、さまざまな場所に分散しています。

そのため、学生は必要な情報を探すのに時間がかかったり、知り合いや先輩の有無によって得られる情報に差が出たりしています。

特に、新入生、編入生、留学生、知り合いや先輩が少ない学生は、授業、サークル、住居、アルバイト、就活などの情報を得にくい場合があります。

TsukuHubは、このような情報格差をなくし、筑波大学生が必要な情報を必要なタイミングで得られる状態を作ることを目的としています。
